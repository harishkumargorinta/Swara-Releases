### What's New in v1.3.0
- **App Logo & Video Splash**: Custom app launcher icons across all screen densities and 16:9 animated video splash screen on launch.
- **Song Options & 3-Dots Menu**:
  - Vertical 3-dots icon on every song row across Playlists, Albums, Search, Home, Library, and Queue.
  - Action bottom sheet: Share, Add to playlist, Add to Queue, Play next, Go to Queue, Go to album, and Go to artist.
- **Home Screen "View All" on Every Section**:
  - "View All" option next to "Play All" for Top Picks, Daily Dose, Recent Plays, New Releases, Trending, 90s, 2000s, and Top Tracks.
  - Instant bottom sheet with full song list, "Play All", "Shuffle", direct "Play Next" queue button, and 3-dots menu.
- **Playback Queue Overhaul**:
  - Excluded past/previously played songs from the queue view.
  - "NOW PLAYING" card with animated equalizer wave.
  - "NEXT IN QUEUE" displaying only upcoming tracks with reordering and removal controls.
- **Multilingual Lyrics & Transliteration**:
  - Romanized English transliteration for Telugu, Tamil, Hindi, Kannada, Malayalam, Punjabi, Bengali, and Gujarati lyrics.
  - Full-screen lyrics view with synchronized LRC karaoke highlighting and tap-to-seek (bottom player bar removed for immersion).
- **Search Redesign**:
  - Removed audio-only Videos filter tab.
  - 2-column colorful Spotify-style browse categories grid with angled artwork.
  - Live search suggestions with search icons and diagonal arrows.
- **Performance & Loading Speed**:
  - Parallel concurrent network calls reduce initial home load time from 15-20s down to ~1-2s.
  - In-memory 5-minute cache for instant 0ms tab navigation.
- **3-Month New Releases Filter**:
  - Filtered home new releases to show songs released from today back 3 months.
